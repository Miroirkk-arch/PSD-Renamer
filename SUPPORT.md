# 常见问题与反馈 / FAQ & support

## 中文

**如何打开？** 下载 Releases 附件中的 Windows ZIP，解压整个文件夹，打开 PSD命名修改.exe。运行依赖必须保留。

**需要 Photoshop 或联网吗？** 不需要 Photoshop。PSD 处理和字典管理离线运行，主动检查更新时访问 GitHub。

**支持哪些平台？** 当前发布 Windows 64 位版本，软件界面为中文；暂未发布 macOS、Linux 或 Windows ARM 原生版本。

**怎么更新？** 退出旧版，将新 ZIP 解压到新文件夹再运行。个人字典位于 %APPDATA%/PSD命名修改；应用设置保存在用户设置中。

**为什么 Source code 下载里没有 exe？** 这是 GitHub 自动打包的仓库文档。请下载名为 PSDNaming-v版本号-win-x64.zip 的发布附件。

**文件打不开或预览不正常？** 在 Issues 中提供软件版本、Windows 版本、文件尺寸、图层数、操作步骤和错误提示。可以用不含私人内容的小型 PSD 重现问题。

**如何反馈？** [报告问题](https://github.com/Miroirkk-arch/PSD-Renamer/issues/new?template=bug_report.md) 或 [提出建议](https://github.com/Miroirkk-arch/PSD-Renamer/issues/new?template=feature_request.md)。请不要提交密码、验证码或私人 PSD 文件。

## English

**How do I run it?** Download the Windows ZIP attached to Releases, extract the entire folder, and run PSD命名修改.exe. Keep all bundled runtime files.

**Do I need Photoshop or internet access?** Photoshop is not required. PSD processing and dictionary management work offline; manual update checks contact GitHub.

**Supported platforms?** Windows x64, with a Chinese application interface. No macOS, Linux, or native Windows ARM release is currently available.

**How do I update?** Close the old app, extract the new ZIP into a new folder, and run it. Personal dictionaries are stored under %APPDATA%/PSD命名修改; application settings are stored in your user settings.

**Why is there no exe in Source code?** GitHub automatically creates those archives from repository documentation. Download the attached PSDNaming-vVERSION-win-x64.zip instead.

**Trouble opening a PSD or rendering a preview?** Include the app version, Windows version, document dimensions, layer count, reproduction steps, and error text in an issue. A small PSD without private content can help reproduce the issue.

**Feedback:** [Report a bug](https://github.com/Miroirkk-arch/PSD-Renamer/issues/new?template=bug_report.md) or [request a feature](https://github.com/Miroirkk-arch/PSD-Renamer/issues/new?template=feature_request.md). Do not submit passwords, verification codes, or private PSD files.
