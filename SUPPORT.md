# 常见问题 / FAQ

## 中文

**如何打开？** 下载 Releases 附件中的 Windows ZIP，解压整个文件夹，打开 PSD-Renamer.exe。运行依赖必须保留。

**需要 Photoshop 或联网吗？** 不需要 Photoshop。PSD 处理和字典管理离线运行，主动检查更新时访问 GitHub。

**支持哪些平台？** 当前发布 Windows 64 位版本，软件界面支持中文、英语、日语；暂未发布 macOS、Linux 或 Windows ARM 原生版本。

**怎么更新？** 退出旧版，将新 ZIP 解压到新文件夹再运行。个人字典位于 %APPDATA%/PSD命名修改；应用设置保存在用户设置中。

**为什么 Source code 下载里没有 exe？** 这是 GitHub 自动打包的应用源码。请下载名为 PSD-Renamer-v版本号-win-x64.zip 的发布附件。



## English

**How do I run it?** Download the Windows ZIP attached to Releases, extract the entire folder, and run PSD-Renamer.exe. Keep all bundled runtime files.

**Do I need Photoshop or internet access?** Photoshop is not required. PSD processing and dictionary management work offline; manual update checks contact GitHub.

**Supported platforms?** Windows x64, with Chinese, English, and Japanese interfaces. No macOS, Linux, or native Windows ARM release is currently available.

**How do I update?** Close the old app, extract the new ZIP into a new folder, and run it. Personal dictionaries are stored under %APPDATA%/PSD命名修改; application settings are stored in your user settings.

**Why is there no exe in Source code?** GitHub automatically creates those archives from application source. Download the attached PSD-Renamer-vVERSION-win-x64.zip instead.
